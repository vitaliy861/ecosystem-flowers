# Результаты обучения

- **classification_report.txt** — общая точность, precision/recall/f1 по каждому классу, матрица ошибок (текстом).
- **confusion_matrix.png** — визуализация матрицы ошибок: какие классы путаются между собой.
- **training_curves.png** — графики loss и accuracy по эпохам (обучение и валидация).

Модель: EfficientNetB0, дообучение на датасете Flowers Recognition (5 классов).
