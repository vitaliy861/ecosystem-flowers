# Мониторинг экосистемы: классификация видов цветов

Демо-решение практикума «Использование предобученных моделей для создания ML-driven продуктов». Классификация пяти видов цветов по фотографиям для поддержки экологического мониторинга.

---

## 1. Обоснование выбранной задачи (бизнес-постановка)

**Тема практикума:** мониторинг экосистем через IT-решения.

**Бизнес-задача:**  
Экологам и специалистам по охране природы нужны данные о видовом составе растений на территориях (луга, поля, обочины). Ручной разбор тысяч фотографий с полевых обследований или с камер наблюдения трудоёмок и подвержен ошибкам. Требуется инструмент, который по фото автоматически определяет вид растения (в данном проекте — один из пяти видов цветов: ромашка, одуванчик, роза, подсолнух, тюльпан), чтобы ускорить учёт биоразнообразия и поддержать принятие решений по охране природы.

**Связь с мониторингом экосистем:** автоматическое определение видов по фото позволяет вести учёт биоразнообразия, отслеживать фенологию и реакцию на изменение климата, оценивать состояние местообитаний и использовать гражданскую науку (разметка фото волонтёрами с последующей выборочной проверкой).

---

## 2. Область и постановка в DS-терминах

- **Область:** Computer Vision (CV).
- **Тип задачи:** классификация изображений (multiclass classification).
- **Вход:** изображение цветка (RGB).
- **Выход:** класс вида (один из пяти) и вероятность принадлежности к классу.
- **Метод:** дообучение (fine-tuning) предобученной свёрточной нейронной сети на датасете с разбиением на train/validation; оценка качества по accuracy, classification_report и confusion matrix.

## 5. Предобученная модель и обоснование выбора

| Модель | Источник предобучения | Где взять в коде |
|--------|------------------------|-------------------|
| **EfficientNetB0** | ImageNet | `tf.keras.applications.EfficientNetB0(weights='imagenet')` (Keras/TensorFlow) |

- Документация: https://keras.io/api/applications/efficientnet/

EfficientNetB0 даёт баланс между точностью и вычислительными затратами, подходит для transfer learning при ограниченном объёме данных. Предобучена на ImageNet; последние слои заменяются на классификатор под 5 классов цветов, часть свёрточных слоёв замораживается, остальные дообучаются на датасете цветов.

## 7. Итоги результатов обучения

Результаты обучения (см. [ноутбук в Colab с выводом](https://colab.research.google.com/drive/1NB5J82KbgKjs-TjX7L9at0oYtrU45-hj?usp=sharing)):

- **Accuracy на валидации:** ~24% (при 10 эпохах, датасет Flowers Recognition).
- **По классам:** лучше всего распознаются **dandelion** (recall ~0.51) и **tulips** (recall ~0.50); **roses**, **daisy** и **sunflowers** — низкий recall (модель часто путает их с другими классами).
- **Матрица ошибок:** наибольшие путаницы — предсказание dandelion или tulips для изображений других классов; по диагонали (правильные предсказания) видно перекос в пользу dandelion и tulips.

В папке **results/** (или в выводе ноутбука в Colab) сохраняются: **classification_report.txt**, **confusion_matrix.png**, **training_curves.png** — общая точность, precision/recall/f1 по классам и графики обучения.

## 8. Итоги и выводы

(По результатам [ноутбука в Colab](https://colab.research.google.com/drive/1NB5J82KbgKjs-TjX7L9at0oYtrU45-hj?usp=sharing).)

**Модель и сохранение.** Модель **EfficientNetB0** дообучена на 5 классах цветов (daisy, dandelion, roses, sunflowers, tulips). Лучшие веса по валидационной точности сохраняются в **checkpoints/**; в ноутбуке доступны графики обучения (loss и accuracy по эпохам) и сохранённый отчёт.

**Оценка по classification report и confusion matrix.** Точность на валидации составляет **~24%** (24.30% в прогоне из ноутбука). Часть классов распознаётся заметно лучше остальных; по другим классам recall близок к нулю — модель чаще относит такие изображения к «популярным» классам. Матрица ошибок показывает сильный перекос: по диагонали выделяются один–два класса с большим числом правильных предсказаний, тогда как остальные классы в основном путаются с ними. В итоге модель склонна предсказывать ограниченный набор классов; остальные регулярно путаются с другими.

**Порог уверенности и ручная проверка.** Для мониторинга экосистем в ноутбуке задан порог уверенности **0.75**. При вероятности ниже порога у примера подписывается «проверка!» — такой результат считается предварительным и рекомендуется ручная проверка специалистом. Это позволяет использовать модель как первый этап отбора, а не как единственный источник решения.

**Модуль подсчёта объектов.** В разделе 9 ноутбука и в **scripts/count_objects.py** реализован модуль подсчёта объектов: по одному изображению выдаётся предсказанный класс, уверенность и признак необходимости проверки; в ноутбуке вывод сопровождается картинками с подписями. При необходимости логику можно расширить на скользящее окно по большому снимку для приближённой оценки обилия на территории — это напрямую поддерживает задачи мониторинга экосистем.
