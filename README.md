# Мониторинг экосистемы: классификация видов цветов

Демо-решение практикума «Использование предобученных моделей для создания ML-driven продуктов». Классификация пяти видов цветов по фотографиям для поддержки экологического мониторинга.

---

## 1. Обоснование выбранной задачи (бизнес-постановка)

**Тема практикума:** мониторинг экосистем через IT-решения.

**Бизнес-задача:**  
Экологам и специалистам по охране природы нужны данные о видовом составе растений на территориях (луга, поля, обочины). Ручной разбор тысяч фотографий с полевых обследований или с камер наблюдения трудоёмок и подвержен ошибкам. Требуется инструмент, который по фото автоматически определяет вид растения (в данном проекте — один из пяти видов цветов: ромашка, одуванчик, роза, подсолнух, тюльпан), чтобы ускорить учёт биоразнообразия и поддержать принятие решений по охране природы.

**Связь с мониторингом экосистем:** автоматическое определение видов по фото позволяет вести учёт биоразнообразия, отслеживать фенологию и реакцию на изменение климата, оценивать состояние местообитаний и использовать гражданскую науку (разметка фото волонтёрами с последующей выборочной проверкой).

---

## 2. Область и постановка в DS-терминах

- **Область:** Computer Vision (CV).
- **Тип задачи:** классификация изображений (multiclass classification).
- **Вход:** изображение цветка (RGB).
- **Выход:** класс вида (один из пяти) и вероятность принадлежности к классу.
- **Метод:** дообучение (fine-tuning) предобученной свёрточной нейронной сети на датасете с разбиением на train/validation; оценка качества по accuracy, classification_report и confusion matrix.

---

## 3. Ссылка на данные

- **Название:** Flowers Recognition (5 классов цветов).
- **Ссылка:** https://www.kaggle.com/datasets/alxmamaev/flowers-recognition

В проекте используется папка **`data/flowers/`** с подпапками по классам: **daisy**, **dandelion**, **roses**, **sunflowers**, **tulips**. В каждой подпапке — изображения в формате jpg или png. Имена папок должны совпадать с указанными (латиницей).

---

## 4. Предобученная модель и обоснование выбора

| Модель | Источник предобучения | Где взять в коде |
|--------|------------------------|-------------------|
| **EfficientNetB0** | ImageNet | `tf.keras.applications.EfficientNetB0(weights='imagenet')` (Keras/TensorFlow) |

- Документация: https://keras.io/api/applications/efficientnet/

EfficientNetB0 даёт баланс между точностью и вычислительными затратами, подходит для transfer learning при ограниченном объёме данных. Предобучена на ImageNet; последние слои заменяются на классификатор под 5 классов цветов, часть свёрточных слоёв замораживается, остальные дообучаются на датасете цветов.
